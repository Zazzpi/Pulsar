Pulsar для Linux x86_64

1. Распакуйте архив в любую папку, например на рабочий стол.
2. Дважды нажмите Pulsar-linux-x86_64.
3. Нажмите «Посмотреть демо без сервера».

Python, Docker и сервер для демо не нужны. При необходимости в свойствах
файла разрешите выполнение как программы (раздел «Права доступа»).

Для показа: найдите «Ромашка», откройте обзор и вкладки, нажмите
«Отслеживать 90 дней», сохраните заметку. В «Мои клиенты» появится наблюдение.
Заметки и наблюдения сохраняются после закрытия приложения.

Это демонстрационные данные. Для реальной WMS нужны адрес HTTPS API Pulsar,
логин и пароль от администратора. Сам по себе адрес PostgreSQL сюда не подходит.

Сборка: Linux x86_64, glibc 2.39 или новее (Ubuntu 24.04+, Debian 13).
На минимальных системах без графических библиотек Qt нужны системные X11/Wayland
библиотеки; на компьютере разработчика с Debian 13 KDE запуск проверен.
Windows-файл Pulsar.exe предназначен для Windows, не для Linux.

Данные хранятся в ~/.local/share/pulsar (или $XDG_DATA_HOME/pulsar).
